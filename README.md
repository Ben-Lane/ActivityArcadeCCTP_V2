This ReadME.TXT provides information on how to correctly open and use this project.

Final Prototype (Unreal Engine 5):

    Github link | https://github.com/Ben-Lane/ActivityArcadeCCTP_V2.git

    How to open | 
    1. Open the ".uproject" file with Unreal Engine 5.3.2.
    2. Run the level.

    Controls |
    1. Click and drag with Right Click (RMB) move throughout the environment.
    2. Click with Left Click (LMB) for buttons, placing/deleting objects in edit mode, play arcade machine games.
